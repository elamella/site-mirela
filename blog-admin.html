    Mettre en ligne : 3 étapes

    La publication en un clic n’est pas disponible ici (page ouverte depuis un dossier, ou service non configuré). Utilisez la méthode manuelle ci-dessous.

    Vous avez des changements pas encore publiés. Ne fermez pas cette page avant d’avoir téléchargé les fichiers ci-dessous.

    1. Téléchargez le fichier des articles.
    2. Téléchargez les images ajoutées (s’il y en a).
      Aucune nouvelle image.
    3. Placez les fichiers dans le dossier du site.
      • posts.js → dossier blog (remplacer l’ancien fichier)
      • chaque image → dossier assets/blog
      Puis rechargez la page du blog pour voir le résultat.
